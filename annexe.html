Section 1

Qu'est-ce que le PSI ?

PSI = Program Structure Interface. Pour chaque fichier, la plateforme construit un arbre : PsiFile (racine) → PsiElement (nœuds) → feuilles (tokens, espaces, commentaires).

🌳

Arbre syntaxique concret

Contient tout le texte, y compris espaces et commentaires — pas un AST abstrait.

🔍

Enrichi

On peut résoudre un identifiant vers sa déclaration (resolve()), obtenir le type, chercher des usages.

🔄

À jour

Reflète le texte du Document après commit — synchronisé avec l'éditeur.

Exemple d'arbre pour int x = a + 1;

Arbre PSI simplifié
PsiMethod
└─ PsiCodeBlock
└─ PsiDeclarationStatement
└─ PsiLocalVariable x
├─ PsiTypeElement int
├─ PsiIdentifier x
└─ PsiBinaryExpression a + 1
├─ PsiReferenceExpression a
├─ PsiJavaToken +
└─ PsiLiteralExpression 1
💡
Outil indispensable : activer le PSI Viewer dans l'IDE sandbox (Tools → View PSI Structure of Current File) pour visualiser l'arbre réel avant d'écrire un visiteur. Nécessite l'option JVM -Didea.is.internal=true dans runIde.

Obtenir le PSI

Java Obtenir le PSI — recettes 
// ① depuis un événement d'action
PsiFile file    = e.getData(CommonDataKeys.PSI_FILE);
Editor editor   = e.getData(CommonDataKeys.EDITOR);
PsiElement elem = e.getData(CommonDataKeys.PSI_ELEMENT);

// ② depuis un VirtualFile
PsiFile f = PsiManager.getInstance(project).findFile(virtualFile);

// ③ depuis un Document
PsiFile f2 = PsiDocumentManager.getInstance(project).getPsiFile(document);

// ④ élément sous le curseur → remonter vers la méthode
PsiElement leaf = file.findElementAt(editor.getCaretModel().getOffset());
PsiMethod method = PsiTreeUtil.getParentOfType(leaf, PsiMethod.class);

// ⑤ classe par nom qualifié
PsiClass c = JavaPsiFacade.getInstance(project)
        .findClass("fr.monequipe.Foo", GlobalSearchScope.projectScope(project));
⚠️
findElementAt renvoie une feuille (souvent un PsiIdentifier ou un token) : toujours remonter avec getParentOfType pour atteindre le nœud voulu.

Visiteurs — pattern Visitor

JavaElementVisitor

Non récursif — on décide quand descendre. Utilisé dans les inspections (buildVisitor). Appeler super.visitXxx(node) pour continuer à descendre.

JavaRecursiveElementVisitor

Descend automatiquement dans tout l'arbre. Pratique mais peut causer un débordement de pile sur de très gros fichiers.

JavaRecursiveElementWalkingVisitor

Variante itérative (pas de récursion) — recommandée pour les gros parcours. Usage : element.accept(visitor).

🔑
Pattern à retenir : surcharger visitXxx(PsiXxx node), faire son traitement, puis appeler super.visitXxx(node) pour continuer à descendre (omettre = couper la branche).
Section 5

Exemple complet : lister les variables d'une méthode

📌
Les paramètres ne sont pas dans le corps de la méthode. Les variables de for-each, catch, lambda sont des PsiParameter, pas des PsiLocalVariable. Ne pas descendre dans les classes locales/anonymes.
Java VariableCollector.java 
public final class VariableCollector {

    public record VarInfo(String name, String type, String kind, int line, PsiVariable psi) {}

    public static List<VarInfo> collect(PsiMethod method) {
        List<VarInfo> result = new ArrayList<>();
        Document doc = PsiDocumentManager.getInstance(method.getProject())
                .getDocument(method.getContainingFile());

        // 1. paramètres de la méthode (hors du corps)
        for (PsiParameter p : method.getParameterList().getParameters()) {
            result.add(info(p, "paramètre", doc));
        }

        // 2. variables du corps
        PsiCodeBlock body = method.getBody();
        if (body == null) return result;  // méthode abstraite ou native

        body.accept(new JavaRecursiveElementWalkingVisitor() {
            @Override
            public void visitClass(@NotNull PsiClass aClass) {
                // ne pas descendre dans classes locales/anonymes
            }

            @Override
            public void visitLocalVariable(@NotNull PsiLocalVariable v) {
                result.add(info(v, "locale", doc));
                super.visitLocalVariable(v);  // descendre dans l'initialiseur (lambda possible)
            }

            @Override
            public void visitParameter(@NotNull PsiParameter p) {
                // for-each, catch, paramètre de lambda
                result.add(info(p, "paramètre interne", doc));
                super.visitParameter(p);
            }
        });
        return result;
    }

    private static VarInfo info(PsiVariable v, String kind, Document doc) {
        int line = doc == null ? -1 : doc.getLineNumber(v.getTextOffset()) + 1;
        return new VarInfo(v.getName(), v.getType().getPresentableText(), kind, line, v);
    }
}
Section 6

Exemple : extraire les conditions atomiques (MC/DC)

Décompose (a && b) || !c en conditions atomiques [a, b, c], en traversant récursivement les opérateurs logiques et les négations.

Java ConditionUtil.java 
public final class ConditionUtil {

    /** Décompose (a && b) || !c en [a, b, c] */
    public static void atomicConditions(@Nullable PsiExpression expr, List<PsiExpression> out) {
        expr = PsiUtil.skipParenthesizedExprDown(expr);
        if (expr == null) return;

        if (expr instanceof PsiPolyadicExpression poly) {
            IElementType op = poly.getOperationTokenType();
            if (op == JavaTokenType.ANDAND || op == JavaTokenType.OROR) {
                for (PsiExpression operand : poly.getOperands())
                    atomicConditions(operand, out);
                return;
            }
        }
        if (expr instanceof PsiPrefixExpression prefix
                && prefix.getOperationTokenType() == JavaTokenType.EXCL) {
            atomicConditions(prefix.getOperand(), out);
            return;
        }
        out.add(expr);  // condition atomique
    }

    /** Toutes les décisions (if, while, for, do, ternaire) d'une méthode */
    public static List<PsiExpression> decisions(PsiMethod method) {
        List<PsiExpression> res = new ArrayList<>();
        method.accept(new JavaRecursiveElementWalkingVisitor() {
            @Override public void visitIfStatement(@NotNull PsiIfStatement s)
                { add(s.getCondition()); super.visitIfStatement(s); }
            @Override public void visitWhileStatement(@NotNull PsiWhileStatement s)
                { add(s.getCondition()); super.visitWhileStatement(s); }
            @Override public void visitForStatement(@NotNull PsiForStatement s)
                { add(s.getCondition()); super.visitForStatement(s); }
            @Override public void visitConditionalExpression(@NotNull PsiConditionalExpression e)
                { add(e.getCondition()); super.visitConditionalExpression(e); }
            private void add(PsiExpression c) { if (c != null) res.add(c); }
        });
        return res;
    }
}

⚠️
resolve() peut renvoyer null (code incomplet, dépendance absente, indexation en cours — dumb mode) : toujours tester avant d'utiliser le résultat.
Scopes disponibles : projectScope(project), allScope(project) (avec bibliothèques), moduleScope(module), fileScope(...).
Section 8

Modifier le code — Write Action

✏️
Toute modification du PSI doit être dans une write action et, pour être annulable (Ctrl+Z), dans une commande. La SAE est surtout en lecture — éviter de modifier le code utilisateur sauf pour des quick-fixes.
Java Write action + PsiElementFactory 
WriteCommandAction.runWriteCommandAction(project, "Ajouter trace", null, () -> {
    PsiElementFactory factory = JavaPsiFacade.getElementFactory(project);
    PsiStatement st = factory.createStatementFromText(
            "System.out.println(\"enter\");", method);
    PsiCodeBlock body = method.getBody();
    body.addAfter(st, body.getLBrace());
    // Reformater après insertion
    CodeStyleManager.getInstance(project).reformat(method);
    // Raccourcir les noms de classes importées
    JavaCodeStyleManager.getInstance(project).shortenClassReferences(method);
}, method.getContainingFile());
