Section 1

Comment trouver le bon point d'extension

1

Documentation officielle

Chercher dans la doc officielle "Extension Point List" sur plugins.jetbrains.com.

2

IntelliJ Platform Explorer

Utiliser jb.gg/ipe — on voit quels plugins utilisent quel EP, avec leur code.

3

Ctrl+clic dans l'IDE

Dans l'IDE de dev : Ctrl+clic sur une balise d'extension d'un plugin.xml existant pour sauter à la déclaration de l'EP.

4

Lire le code JetBrains open source

Lire le code d'un plugin JetBrains open source qui fait quelque chose de similaire à ce que vous voulez implémenter.

Section 5

Exemples XML prêts à adapter

Inspection (localInspection)

📄
Fichier obligatoire : resources/inspectionDescriptions/ComplexCondition.html — le nom correspond au shortName.
XML plugin.xml — inspection 
<extensions defaultExtensionNs="com.intellij">
    <localInspection language="JAVA"
                     shortName="ComplexCondition"
                     displayName="Condition complexe"
                     groupName="SAE Analyzer"
                     enabledByDefault="true"
                     level="WARNING"
                     implementationClass="fr.monequipe.sae.analysis.ComplexConditionInspection"/>
</extensions>

Gutter (icônes en marge)

XML plugin.xml — lineMarkerProvider 
<codeInsight.lineMarkerProvider language="JAVA"
    implementationClass="fr.monequipe.sae.ui.CoverageLineMarkerProvider"/>

Page de réglages

XML plugin.xml — projectConfigurable 
<projectConfigurable parentId="tools"
                     instance="fr.monequipe.sae.ui.AnalyzerConfigurable"
                     id="fr.monequipe.sae.settings"
                     displayName="SAE Analyzer"/>

Action avec raccourci clavier

XML plugin.xml — action complète 
<actions>
    <action id="fr.monequipe.sae.RunAnalysis"
            class="fr.monequipe.sae.actions.RunAnalysisAction"
            text="Analyser la méthode"
            description="Lance l'analyse statique sur la méthode sous le curseur">
        <add-to-group group-id="AnalyzeMenu" anchor="last"/>
        <add-to-group group-id="EditorPopupMenu" anchor="last"/>
        <keyboard-shortcut keymap="$default" first-keystroke="ctrl alt G"/>
    </action>
</actions>

ToolWindow + postStartupActivity

XML plugin.xml — toolWindow + startup 
<extensions defaultExtensionNs="com.intellij">

    <toolWindow id="SAE Analyzer"
                factoryClass="fr.monequipe.sae.ui.AnalyzerToolWindowFactory"
                anchor="right"/>

    <postStartupActivity
        implementation="fr.monequipe.sae.services.ProjectScanActivity"/>

    <notificationGroup id="SAE Notifications" displayType="BALLOON"/>

</extensions>

JavaProgramPatcher (axe dynamique)

XML plugin.xml — programPatcher 
<extensions defaultExtensionNs="com.intellij">
    <java.programPatcher
        implementation="fr.monequipe.sae.dynamic.AgentProgramPatcher"/>
</extensions>

Récapitulatif — Actions vs Extension Points

🖱️

Action (<action>)

Déclencheur manuel — l'utilisateur doit cliquer (menu, bouton, raccourci clavier) pour que l'action s'exécute.

Classe de base : AnAction

Méthode : actionPerformed(AnActionEvent e)

🔄

Extension Point (<extensions>)

IntelliJ appelle automatiquement à un moment précis de son cycle de vie, sans intervention de l'utilisateur.

Exemples : ouverture de fichier, frappe au clavier, ouverture du projet.
